# T30. Creature variants

**Read first:** `AGENTS.md`, `DESIGN.md` (section 3.5 and the standing rules), `src/lib/game/types.ts`, `src/lib/game/stats-from-items.ts`

Three things currently describe a creature: **how much** work (stage), and **what** the work is about (species). This adds the third: **how the work is shaped**.

Two gardens with identical XP can be entirely different things. Twelve notes densely cross-linked into a web, versus twelve isolated notes that never reference each other, produce the same creature today. They represent very different kinds of thinking.

## The form this takes

Botanists mark varieties of a species with `var.` — *Quercus robur* var. *fastigiata*. That is exactly what a variant is in the specimen world this design is built on, so the variant lives in the **name**:

```
SPECIMEN 2 OF 4
Mossling  ·  var. woven
```

**No sprite changes.** This works with any art source, so swapping PokeAPI for original art later does not break it.

**No glow.** `DESIGN.md` and the taste skill both ban outer glows outright as an AI tell, and this project has held that line on every surface. A glowing creature would be the only thing on the site that looks imported from elsewhere. The variant name in the accent colour is the visual treatment.

If it reads too quietly once built, the escalation is a **doubled rule** on the specimen plate border, the way a mounted specimen of note gets a heavier frame. Try the quiet version first and say whether it needs more.

## The four variants

Derive from `GardenStats`, which already carries everything needed.

| Variant | Shape of work | Signal |
|---|---|---|
| `woven` | Densely interconnected | High resolved wikilinks per note |
| `steady` | Consistent over time | A long unbroken streak of writing or commits |
| `deep` | Depth over breadth | Few notes, high words per note, mostly evergreen |
| `broad` | Wide-ranging | Many distinct tags relative to note count |

**Most gardens should qualify for none.** That is the point: a variant is worth having because it is uncommon. Pick thresholds that a typical garden misses. Do not tune them so everyone gets one.

**A creature has at most one variant.** If several qualify, pick deterministically by a documented precedence order, never at random. Say what order you chose and why.

**Thresholds are ratios, not counts.** `woven` must not simply mean "wrote a lot", or it becomes a second XP bar. Use links per note, words per note, tags per note. A nine-note garden and a nine-hundred-note garden should both be able to earn `woven`.
