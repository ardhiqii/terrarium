# T8. Browser extension

**Group D** · depends on T6 (done) · parallel-safe with T7
**Read first:** `AGENTS.md`, `ROADMAP.md` product definition, `src/app/api/creature/route.ts`, `src/lib/game/types.ts`

The engagement engine. This is what puts creatures into GitHub repo lists so other developers see them, and it is the reason the whole public API exists.

Biggest remaining task. It is a **separate build from the Next app**, self-contained under `extension/`.

## Why an extension at all

It is the only way to inject live HTML into a site you do not control. It also removes the constraint that limits T7: inside an extension there is no camo proxy, so **real animated sprites work**, updates are instant, and nothing is cached against you. Use that. This surface gets the good version.

## Files you own

```
extension/**            (everything, self-contained)
```

## Files you must NOT touch

- Anything under `src/`, `content/`, or the Next config. T7 is building `src/app/api/creature.svg/` in parallel right now.
- Do **not** add the extension to the Next app's `package.json`. It is a separate artifact with its own build, or no build at all if you keep it dependency-free.

Keeping it dependency-free (plain JS, no bundler) is a legitimate and preferred choice here. Justify whichever you pick.

## Requirements

### 1. Manifest V3

- Host permissions for `github.com` and your API origin **only**. Over-broad permissions get extensions rejected from the store, and MV3 is strict about this.
- No remote code execution. MV3 forbids it, so everything ships in the package.
- Make the API base URL configurable, defaulting to something sensible for local development.

### 2. Content script

Inject a creature into GitHub repo lists:
- `github.com/<user>?tab=repositories` (the repo list)
- The profile page pinned-repos grid

**Fail silently and completely.** GitHub changes its DOM constantly. If your selectors do not match, inject nothing and move on. Breaking someone's GitHub page is far worse than showing no creature. Wrap injection in try/catch and never throw into the host page.

Do not fight the page: no layout thrash, no `!important` wars, no reflow loops. Use a shadow root or a tightly namespaced class prefix so nothing leaks into GitHub's styles or vice versa.

### 3. Batching and caching, the part that decides whether this is viable

A repo list can have 30 repos. **Do not make 30 API calls.**

- One batched request per page, or a small bounded number.
- Cache in `chrome.storage.local` with a TTL of at least one hour, keyed by handle and repo.
- On a cache hit, make **zero** network calls.
- Debounce navigation. GitHub is a SPA-ish site that swaps content without full reloads, so guard against firing repeatedly.

If T6's endpoint needs a batch shape it does not currently have, **do not edit T6's route**. Report exactly what you need and work with per-repo calls plus aggressive caching for now.

### 4. The popup, the pokedex

The user's garden creature, their repo creatures, and the item drawer. This is the "pokedex in the browser" surface. Let the sprites animate here.

An input to set which handle to display, persisted in `chrome.storage`.

### 5. Quality bar

- Respect `prefers-reduced-motion`, and stop animation when it is set.
- Readable against **both** GitHub themes. GitHub sets `data-color-mode` on `<html>`, so read it rather than guessing.
- No console spam. Errors go to a single debug flag, off by default.
- Disabling the extension must leave GitHub completely untouched.

## Store submission decision point

Do **not** submit to the Chrome Web Store as part of this task.

Publishing to the store is public distribution under a developer identity, which is a materially different posture from a personal project using Pokemon sprites. The `SpriteSource` abstraction from T2 exists precisely so original art can be swapped in cheaply before that step. Flag this in your report and stop at "loads unpacked."

## Done when

Verified by actually doing it, not asserted:

1. **Loads unpacked in Chrome** with no manifest or console errors.
2. **Creatures appear in a real GitHub repo list.** Screenshot it.
3. Popup opens, shows a creature, sprites animate.
4. A second page load makes **zero** network calls. Prove it from the network panel or a counter.
5. Selectors failing (simulate by breaking one) injects nothing and does not error into the page.
6. Works in both GitHub light and dark themes. Screenshot both.
7. Disabling the extension leaves GitHub pristine.

The Next app's gates must also still pass, since you should not have touched it:

