This fictional project is part of the starter dataset. It gives a new install a
realistic project page without shipping anyone's personal work.

## Goal

Build a tiny tool that watches a local Markdown folder, detects meaningful
changes, and turns those changes into explainable companion events.

## Decisions

- Keep note contents on the user's device by default.
- Use stable fingerprints and event IDs so scans are replay-safe.
- Keep the provider layer replaceable so original artist assets can replace the
  current Pokémon prototype later.
- Show evidence beside XP rather than hiding a quality score behind AI.

## Next steps

1. Add more source adapters.
2. Make the event ledger importable across devices.
3. Connect the marketplace contract to artist-owned companion art.
