This is sample content for a fresh Terrarium installation. It exists so a
clone has something to browse immediately; replace it with your own notes when
you are ready.

Terrarium is an offline-first companion layer for work that already happens in
your tools. Notes can stay in a local Markdown folder, while GitHub can provide
optional verified development activity.

Start with [[How Companions Grow]], then see [[Mount Existing Notes]] and
[[GitHub Activity and XP]]. The [[Terrarium Demo Project]] shows how a project
can connect the whole graph.
