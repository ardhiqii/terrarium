GitHub is optional for local play, but useful for verification and sync. When
connected, Terrarium can read public commits, pull requests, releases, issues,
and CI outcomes. It stores derived events rather than copying a repository's
source code into the product.

The rules reward evidence of work and outcomes, not an AI opinion about
quality. AI-assisted work is not penalized or given a special multiplier. The
public activity ledger shows what was counted and where it came from, so other
people can judge the history for themselves.

The browser extension uses the public creature endpoint to show companions next
to GitHub repositories. It is an optional viewing surface, not a requirement
for local progression.
