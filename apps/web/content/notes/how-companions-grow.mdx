Terrarium starts with one companion. The user may choose a weighted companion
from existing work, choose a surprise, or keep the starter and connect sources
later.

The active companion receives XP from normalized work events. A new note,
resolved wikilink, qualifying work session, merged pull request, release, or
successful CI result can contribute. Stable event IDs and daily caps prevent
refreshes and scripted volume from farming progress.

At encounter thresholds, Terrarium draws one persisted companion result. The
result is random but influenced by transparent signals such as file types,
languages, tags, links, and activity shape. Duplicate results become
family-specific Essence instead of disappearing.

XP belongs to each companion separately. Switching the active companion is
always allowed, so different companions can represent different chapters of a
person's work.
