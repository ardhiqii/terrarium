## Priority 2: accessibility

The creature UI was built fast and never audited.

- **Keyboard.** Every interactive element reachable and operable, visible focus rings that meet contrast in both themes. No focus traps.
- **Screen readers.** Sprites need meaningful alt text or `aria-hidden` if purely decorative. The XP bar should expose its value, for example `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax`. Locked items must announce that they are locked, not just look dimmed.
- **Colour independence.** Verify no state is conveyed by colour alone anywhere. `StageLine` already does this correctly, so use it as the reference.
- **Contrast.** WCAG AA minimum for body text, both themes, every route.
- **Reduced motion.** Confirm every animation actually collapses under `prefers-reduced-motion: reduce`, including the PokeAPI GIFs, which do **not** stop on their own. A GIF keeps animating regardless of the media query, so it needs a real solution: swap to a static frame, or pause via a `<picture>`/canvas approach. This is the one most likely to have been missed.
