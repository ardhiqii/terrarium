# T21. Graph: make it feel like a network

**Depends on** T20 (done)
**Read first:** `AGENTS.md`, `DESIGN.md` sections 2 and 6, `src/components/graph/GardenGraph.tsx`

T20 fixed the graph's *problems*: it opens composed, hubs are sized by backlink count, notes and projects are distinguishable, labels no longer collide. All of that stays.

What it does not yet have is **presence**. It currently reads as nine grey circles joined by hairlines. The feedback, verbatim: *"its just too simple"*, and it should feel *"kinda network design ish"* while staying simple and matching the typographic style already established.

## The brief

Make it look like a **network diagram**, not a scatter of dots. The reference the user could not name is the familiar knowledge-graph look: Obsidian's graph view, a constellation map, a node-link diagram that feels alive and interconnected rather than sparse.

Crucially: **more presence, not more decoration.** The archive theme stays. One accent, neutrals, sharp edges, nothing neon, no glow soup, no AI-purple gradients.

## Concrete directions, use judgement

The edges are where most of the win is. Right now they are flat hairlines and they carry no information.

- **Curved links** instead of straight ones. `linkCurvature` around 0.15 to 0.25 reads as organic and immediately looks less like a diagram of dots.
- **Link weight and opacity should mean something.** A link between two hubs can be stronger than a link to a leaf. Fade distant or weak links so the eye follows the dense core.
- **Directional particles.** `react-force-graph-2d` supports `linkDirectionalParticles`. A small number of slow-moving particles along edges is the single biggest "this is a living network" cue. Keep it restrained: 1 to 2 particles, slow, low opacity, accent-tinted. **Must respect `prefers-reduced-motion`** and drop to zero when set.
- **Hover should light up a neighbourhood.** On node hover, emphasise that node plus its direct links and neighbours, and dim everything else. This is the interaction that makes a graph feel explorable rather than decorative.
- **Node depth.** A subtle ring or halo on hubs, or a thin accent stroke, so nodes read as objects rather than flat fills.
- **Background.** Consider a very low-contrast dot grid or subtle vignette to give the canvas a sense of space. Must be barely there. If it is noticeable as a texture, it is too strong.

## Typography

The user specifically likes the current text treatment, so **keep the label font, size, and casing exactly as they are.** Improve legibility only: a subtle halo or backing behind label text so it survives being drawn over a link, which is standard in node-link diagrams.

## Hard constraints

- One accent colour. Neutrals for everything else. No second hue.
- Theme-reactive: keep the existing runtime `getComputedStyle` token read, since canvas cannot resolve CSS variables.
- `prefers-reduced-motion` kills all particle motion and any animated transition. The graph must still open fully settled.
- Do not regress T20's wins: composed on load, hub sizing, shape-based note/project distinction, no label collisions.
- Performance: this runs on every `/graph` visit. Particles and hover recomputation must not tank frame rate. The current garden is 9 nodes, but it should still behave at 100.
