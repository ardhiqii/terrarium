## The problem

T13 fixed outline contrast by moving local sprites to a `--sprite-outline` CSS token that flips per theme. That works for the seven item sprites and the local fallback creatures.

It does **not** reach the four creature stages, which now render as PokeAPI GIFs through `CreatureSprite`. Those have dark outlines baked into the pixels, and no CSS token can change them. On dark mode's `--paper-raised` (`#1b1b1f`) they very likely have exactly the melting-edge problem T13 just fixed for items.

This is the most prominent element on the home page and the bestiary, so it matters more than the bug T13 fixed.

## First: confirm it is real

**Do not fix before measuring.** Render the creature in dark mode, screenshot it, zoom in on the silhouette edge, and judge whether the outline actually loses definition against the background. If it reads fine, say so and stop. A fix that is not needed is worse than no fix.

Report what you saw either way.

## If a fix is needed

The sprite is a raster GIF, so the fix has to work from outside the pixels. Options, in rough order of preference:

1. **A halo via `drop-shadow`.** `filter: drop-shadow(0 0 1px var(--sprite-halo))` follows the alpha silhouette rather than the bounding box, which is exactly what is wanted. Stack two or three at different offsets for an even outline if one is too faint. Apply in dark mode only, or use a token that resolves to transparent in light mode.
2. **A lighter backing behind the sprite** in dark mode, so the dark outline has something to contrast against. Simpler, but changes the specimen-plate look and risks reading as a mismatched tile.

Constraints:
- Must not blur the pixel art. `image-rendering: pixelated` and integer scaling stay intact.
- Must apply to the remote path only. Local sprites already handle themselves through `--sprite-outline`, and double-treating them would look wrong.
- Both themes verified. The fix must be invisible in light mode, not merely tolerable.
- No layout shift. A filter must not change the element's box size.
